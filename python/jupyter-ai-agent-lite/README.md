# jupyter-ai-agent-lite

The building blocks of in-browser AI personas for [Jupyter AI](https://github.com/jupyterlab/jupyter-ai) in JupyterLab, Notebook 7 and JupyterLite.

The package provides the pieces an in-browser persona needs: a registry of tools (JupyterLab commands, web fetch, skills), a registry of agent skills, the settings shared by the personas (command approvals, chat rendering of command outputs, skills paths) and the OpenRouter sign-in helpers.

The [Jupyternaut persona](https://pypi.org/project/jupyternaut-lite/) is built on it.

## Install

```bash
pip install jupyter-ai-agent-lite
```
